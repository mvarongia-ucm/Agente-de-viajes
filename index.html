Recopilación de Perfil

Descripción del Paso
El Root Agent inicia el flujo conversacional. Su tarea es hacer preguntas lógicas y secuenciales en lenguaje natural al usuario para recopilar y estructurar los parámetros básicos del viaje. Si el usuario pide "ayuda a explorar", activa el modo exploración y consulta si el viaje es nacional o internacional.
Datos que recolecta / Variables
traveler_profile: {
  planned_destination: string | null,
  destination_scope: "nacional" | "internacional",
  transport_mode: "avión" | "auto",
  origin_country_name: string,
  duration_days: number,
  num_people: number,
  ages: string[],
  travel_dates: string,
  travel_style: string
}
